Browser bookmarks, a local file, a hosted bookmark manager, and Bracemark can all keep addresses you want to find again. Choose by the work you need the collection to do and where you want it stored.

## Compare the questions that matter

| If you need…                                                                   | Consider…                                      | Check before you move                                                       |
| ------------------------------------------------------------------------------ | ---------------------------------------------- | --------------------------------------------------------------------------- |
| A small set of sites in one browser                                            | That browser’s bookmarks                       | Whether its own account sync covers your other devices and browsers         |
| A file you can inspect and keep without signing in                             | An HTML bookmarks file or another local format | How you will update, search, and back it up yourself                        |
| Previews or search processed on a provider’s server                            | A hosted manager that offers them              | What the provider can read, store, and export                               |
| Lists, tags, and search across the web app and phone apps, with encrypted sync | Bracemark                                      | Search runs on each device; there is no email password reset or shared list |

For example, [Chrome can sync its bookmarks](https://support.google.com/chrome/answer/165139?hl=en) across signed-in Chrome devices, and [Firefox Sync can sync bookmarks](https://support.mozilla.org/en-US/kb/how-do-i-set-sync-my-computer) through a Mozilla account. Bracemark adds a separate collection you can use in different browsers and apps; it also adds an account password and recovery code you must keep.

You can [import browser bookmarks](/docs/import) and [export them again](/docs/export). Try the free plan with the links you actually use, and keep an export before you change your existing setup. For the data boundary, read [how encryption and search work](/docs/how-encryption-and-search-work).
