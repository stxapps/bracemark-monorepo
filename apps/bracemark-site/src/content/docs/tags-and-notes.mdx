A link can have several tags, while it belongs to one list. A note is text attached to one link. Both sync with that link and are encrypted on your device before upload.

## Add tags and a note

When saving, open “List, tags & note”. Choose existing tags or type a new one, and write the note. To change them later, open the link’s menu and choose Edit. “Edit note” takes you straight to the note. You can also manage tag names in Settings → Tags. Removing a tag there removes it from the links that use it.

Use a list for a home and tags for cross-cutting subjects: a link can live in Work and carry both Research and Read later. Tags don’t nest.

The basic search box finds titles and addresses. To search note text, use the <PlanName plan="plus" /> advanced search editor’s “Note contains” field. See [search](/docs/search).
