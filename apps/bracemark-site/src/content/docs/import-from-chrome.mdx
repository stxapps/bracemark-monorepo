Chrome exports its bookmarks as an HTML file. You can bring that file into Bracemark without removing the bookmarks from Chrome.

## Export from Chrome

On a computer, open Chrome’s menu and choose Bookmarks and lists → Bookmark Manager. In Bookmark Manager, open its menu and choose Export Bookmarks. Save the `.html` file somewhere you can find it. [Google’s current export instructions](https://support.google.com/chrome/answer/96816?hl=en) show the same path if the menu has moved.

## Import into Bracemark

Open [Settings → Data](/docs/import#where-to-find-it), choose Import data, and select the HTML file. Chrome folders become lists; titles and saved dates come across when the file contains them. The file stays on your device, and links already saved are skipped. [Import your links](/docs/import) explains what happens if the file has more new links than your plan allows.

After the import, check a few folders and links before changing your Chrome bookmarks. The two collections do not stay connected: new Chrome bookmarks need another export and import, or you can save directly with the [browser extension](/docs/get-the-apps).
