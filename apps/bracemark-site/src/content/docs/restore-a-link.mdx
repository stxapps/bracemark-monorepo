Remove sends a link to Trash. It stays there until you delete it permanently, so you can bring it back.

## Bring a link back

Open Trash, find the link, and choose Restore from its menu. You can select several links there and restore them together. They return to My List: the link doesn’t retain the list it came from, so move it afterward if you want it somewhere else.

If you try to save an address already in Trash, the save form offers Restore. Choose that to bring the existing link back rather than create another copy.

Deleting permanently removes the link rather than moving it to another list. An earlier edit is different: saving a new title, note, or set of tags replaces the old value, and there is no edit history to undo. A [Bracemark backup](/docs/export) can restore a deleted link, but importing it won’t overwrite a link that still exists on the device.
