Pocket shut down in July 2025, and its export window has closed. If you already downloaded a Pocket export, Bracemark can read the `.zip` or the `.csv` inside it. Mozilla’s [Pocket shutdown notice](https://support.mozilla.org/en-US/kb/future-of-pocket) has the service and export dates.

## Import a file you kept

Open [Settings → Data](/docs/import#where-to-find-it), choose Import data, and select your Pocket `.zip` or `.csv`. You can use the ZIP directly; you do not need to extract the CSV first. Saved links come in as links, and a link marked archived goes to Archive. Links already present are skipped.

The file is read on your device and is not uploaded as a file. If you hit your plan’s link limit, the import shows what will fit before saving anything. See [import your links](/docs/import#if-the-file-holds-more-than-your-plan-allows) for the choices.

If you do not have an export from before Pocket’s deadline, there is no current Pocket export path to follow. A copy you previously saved in another format may still work; the [import formats](/docs/import#which-file-to-use) list the files Bracemark accepts.
