Brace.to exports your data as a `.txt` file. You can import that file directly into Bracemark.

## Export from Brace.to

Open Settings → Data → Export All Data, then choose **Export All My Data**. [Brace.to’s export guide](https://docs.brace.to/import-export) shows the same path.

In a browser, the file downloads to your computer. On iOS, save the file to Files from the share sheet. On Android, Brace.to saves it to Downloads. The filename starts with `Brace.to data` and ends in `.txt`.

If Brace.to says some download requests failed, export again before importing. That warning means the file may be missing data.

## Import into Bracemark

Open [Settings → Data](/docs/import#where-to-find-it), choose Import data, and select the `.txt` file. You don’t need to rename or convert it. Bracemark reads the file on your device; the file itself isn’t uploaded.

Links and their saved dates, lists, tags, pins, titles you set, and custom images come across. My List, Archive, and Trash remain the corresponding lists. Brace.to’s fetched preview images, favicons, and settings don’t come across. New previews can appear later according to your [preview settings](/docs/link-previews).

Check a link in each list you use, plus a tagged or pinned link and a custom image if you have one. For a very large export, import in a browser on a computer: the whole file is read into memory, which can be harder for a phone to handle. [Import your links](/docs/import) explains duplicates, plan limits, and what to do if an import stops partway.

The export file contains your data in plaintext. Delete it from your device when you no longer need it.
