You need a username and a password. We don’t ask for an email address or a card to create an account.

## Create your account

1. Open the <AppLink path="/create-account">web app</AppLink> or the iPhone or Android app and choose Create account.
2. Choose a username. The password field starts on a set of random words; you can change them to your own, and if your browser suggests a password, you can take that instead. Then choose Create account, and save the password when your browser or password manager offers to, or in another place you can reach later.
3. Create a recovery code when the app offers it, and save it. You can skip this and make a code later in Settings → Account, but until you do, your password is the only way back in.
4. Sign in with the password you saved, to check that it works. If you didn’t save it, choose Forgot your password? Show it again. You can skip this too.

<Figure name="recovery-code" />

Your username and password open the same encrypted data on each device. The password doesn’t reach our servers. We cannot send a reset link or recover the account if both the password and recovery code are lost. See [what to do if you lose your password](/docs/lost-password).

## Keep the two ways in separate places

Keep the recovery code apart from your password — for example, keep the password in a password manager and print the code. Anyone with either one can sign in to your account. You can replace the code later while you still have access to an account door. [Where to keep your password](/docs/where-to-keep-your-password) has the options, and how to check your copy works.
