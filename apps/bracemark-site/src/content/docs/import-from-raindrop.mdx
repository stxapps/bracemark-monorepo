Raindrop.io can export HTML bookmarks or CSV. Use HTML for Bracemark: its folder nesting is explicit, while a CSV collection name containing “ / ” can be read as a nested path.

If you only have a CSV file and need browser bookmarks HTML, use our [bookmark file checker and converter](/tools/bookmark-converter). It shows skipped rows and field losses before you download. Bracemark can import the original CSV directly; conversion isn’t required here.

## Get the HTML file

In Raindrop.io, open Settings → Backups, choose Create new, and download the HTML backup when it is ready. Raindrop.io describes this in its [export help](https://help.raindrop.io/export). Its backup doesn’t include links in Trash.

## Import and check the result

Open [Settings → Data](/docs/import#where-to-find-it) in Bracemark, choose Import data, and select the HTML file. Collections become lists, nested collections remain nested, notes come across, and highlights are added to each link’s note as quotes. Favorites receive a Favorites tag. Covers, excerpts, highlight colours, and the PDFs and images you uploaded to Raindrop.io don’t come across.

Check a nested collection and a link with a note after import. The original file isn’t changed, and duplicates already in Bracemark are skipped. [Import your links](/docs/import) covers the plan limit and how to resume an interrupted import.
