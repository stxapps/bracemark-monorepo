Raindrop.io can export HTML bookmarks or CSV. Use HTML for Bracemark: its folder nesting is explicit, while a CSV collection name containing “ / ” can be read as a nested path.

## Get the HTML file

In Raindrop.io, open Settings → Backups, choose Create new, and download the HTML backup when it is ready. Raindrop.io describes this in its [export help](https://help.raindrop.io/export). Its backup does not include links in Trash. Uploaded files such as PDFs and images need a separate export from Raindrop.io; the bookmarks file does not carry them.

## Import and check the result

Open [Settings → Data](/docs/import#where-to-find-it) in Bracemark, choose Import data, and select the HTML file. Collections become lists, nested collections remain nested, notes come across, and highlights are added to each link’s note as quotes. Favorites receive a Favorites tag. Covers, excerpts, and highlight colours do not come across.

Check a nested collection and a link with a note after import. The original file is not changed, and duplicates already in Bracemark are skipped. [Import your links](/docs/import) covers the plan limit and how to resume an interrupted import.
