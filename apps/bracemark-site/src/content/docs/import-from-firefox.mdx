Firefox can export bookmarks as an HTML file for Bracemark to import. Exporting leaves the Firefox bookmarks in place.

## Export from Firefox

On a computer, open Firefox’s Bookmarks menu and choose Manage bookmarks. In the Library window, open Import and Backup → Export Bookmarks to HTML, then save the file. [Mozilla’s export instructions](https://support.mozilla.org/en-US/kb/export-firefox-bookmarks-to-backup-or-transfer) show this path. If the bookmarks are only on your phone, first bring them into desktop Firefox through Firefox Sync, then export there.

## Import into Bracemark

Open [Settings → Data](/docs/import#where-to-find-it), choose Import data, and select the `.html` file. Folders become lists, and existing links are skipped. [Import your links](/docs/import) covers dates, titles, duplicates, and plan limits.

Check the resulting lists and a few links before changing anything in Firefox. The import is a copy at that moment, not a live connection. For new pages, save through the [Firefox browser extension](/docs/get-the-apps) or the app.
