You can use Bracemark in a browser, on an iPhone or Android phone, and through a browser extension for Chrome or Firefox. The <AppLink path="/">web app</AppLink> also works on tablets; the native apps are made for phones.

## Choose how you want to save

- **Browser:** open the <AppLink path="/">web app</AppLink>, sign in, and use Add link. It works without a browser extension.
- **Chrome or Firefox:** install the browser extension from the links on the [home page](/). Sign in inside its popup, even if you are already signed in to the web app. It reads the tab you are saving and can fill in a title and image from that page.
- **iPhone or Android:** install the app from the links on the [home page](/). You can add a URL in the app or share a link to it from another app.

Sign in with the same username and password on each device. Each device keeps its own local copy and syncs encrypted changes when connected. See [sync and devices](/docs/sync-and-devices) for what happens offline.
