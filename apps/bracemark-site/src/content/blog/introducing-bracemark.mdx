## What you can use in this release

Bracemark is an end-to-end encrypted bookmark manager. In this first release, you can save a link in the web app, in the iOS or Android app, or with the Chrome or Firefox browser extension. Give it a title, put it in a list, and add tags or a note when they help you find it later. [Get the apps](/docs/get-the-apps) shows where each one fits.

In the web and mobile apps, you can browse and search the links already on that device while offline. Changes you make there wait until it reconnects, then sync to your other devices. Opening a saved link’s live page still needs a connection.

## Why we made each link a file

We made each link, list, and tag its own encrypted file. Edits to different links can sync independently. Your device encrypts the files before upload. Our account service coordinates sync, and storage holds the ciphertext. Neither has a key to read your saved links. The account service still holds the details needed to sign you in and run sync, including your username and sessions.

That choice has a cost when two devices edit the same link before either sees the other change. The later committed edit wins. We have no readable earlier version on our server to merge or restore. [Sync and devices](/docs/sync-and-devices) explains that case in detail.

Page previews have a separate boundary. The mobile apps fetch them on the device. If you choose server previews in the web app, our separate preview service receives a link’s address so it can fetch the page’s title or image. The saved link still syncs as encrypted data. [Security](/security) and [link previews](/docs/link-previews) explain both paths.

## What that choice costs

Search runs on the copy each device has, so a new device needs to sync before it can find links saved elsewhere. There are no shared lists. Your password and your recovery code are the only two ways into your account, and we don’t have a copy of either, so keep them in separate places. If you skipped the code when you signed up, create one in Settings → Account. If both are lost, there is no way back in, and we can’t make one. [How encryption and search work](/docs/how-encryption-and-search-work) walks through the data path and the tradeoffs.

## Bring your links, and keep a way out

You can [import links](/docs/import) from a browser bookmarks file, another supported export, or a Bracemark backup. Before you change the old collection, check a few imported lists and links. Every plan can [export](/docs/export) a readable Bracemark backup or a format another app can use. Anyone with that export file can read it, so keep it somewhere you trust. It is a separate copy you control, not the live sync path.

You can start with the free plan. [Get the apps](/docs/get-the-apps) has the entry points, and [pricing](/pricing) has the current plan details.
