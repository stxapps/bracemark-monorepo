# bracemark-expo 1.2.0

## App Store

```text
Long lists of links now scroll more smoothly, with less blank space when you scroll fast.

• On landscape iPad, drag the sidebar’s edge to make it wider or narrower. Double-tap the edge to return to the default width.
• Hold a list or tag in the sidebar to read its full name and, for a nested one, where it sits.
• The sidebar and the Lists and Tags pages in Settings open faster with many lists and tags: the first rows appear straight away, and the rest follow.
• The sheet for saving a link from another app uses less memory.
• Fixed: a sheet or dialog didn’t scroll if your drag started on a label or in the gap between two rows.
• Fixed: the sidebar and the Tags page in Settings briefly said “No tags yet” in a library with tags.

Found a bug, or need help? bracemark.com/support
```
