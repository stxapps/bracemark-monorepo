# bracemark-expo 1.1.0

## App Store

```text
Bracemark now runs on iPad, and in every orientation on iPhone and iPad.

• Faster sync, especially the first sync of a large library: sync steps now run in parallel, and files go through our API instead of straight to storage.
• Sync progress: the first sync shows a progress bar, a percentage, and a count, e.g. “1,240 of 3,600 items”. Later syncs show the same in Settings → Data while they run.
• Fixes: exporting a large library no longer stalls, and the sheet for saving a link from another app no longer sits under the keyboard.

Found a bug, or need help? bracemark.com/support
```
