# bracemark-extension 1.1.0

## Firefox Add-ons

```text
Sync is faster, and you can see how far it has got.

- Faster sync, especially the first sync of a large library: sync steps now run in parallel, and files go through our API instead of straight to storage.
- Sync progress: the sync status at the bottom of the popup shows a percentage while it runs. Open it to see a progress bar and a count, e.g. “1,240 of 3,600 items”.
- You can close the popup during a first sync. It keeps running in the background, and if the browser stops it partway through, it picks up where it left off.
```
