# bracemark-extension 1.2.0

## Firefox Add-ons

```text
Bracemark now opens in the Firefox container you’re using.

- The popup’s buttons that open the web app now use the same container as your current tab. If you’re signed in to the web app in that container, you won’t land on the sign-in page.
- This takes a new permission, cookies, which is what Firefox requires to open a tab in a container. The browser extension doesn’t read your cookies.
- The options page now has a Sign in button, which opens the toolbar popup.
- Fixed: clicking the List or Tags label with its picker open reopened the picker and cleared your search. It now closes the picker.

Found a bug, or need help? bracemark.com/support
```
